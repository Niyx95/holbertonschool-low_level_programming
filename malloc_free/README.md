## Overview

This directory contains all exercises regarding malloc and free functionality in C programming language.

### 0-create_array.c
- function that print an array of hex times size, of char based on ASCII table.

### 1-strdup.c
- function that returns a new allocated pointer with a copy of a exeisting sring.

### 2-str_concat.c
- function that returns a new memory with a concatenated string.

### 3-alloc_grid.c
- function that return a pointer to a 2d grid array of ints.

### 4-free_grid.c
- function that frees the memory used by 3-alloc_grid.c
