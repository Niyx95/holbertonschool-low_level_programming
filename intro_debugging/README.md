## Overview
This directory contains all exercises provided by Holberton Australia for debugging intro module.

### sum_to_n.c
- C program that computes the total sum of an integer after an enumeration with a loop.

### multiplication_table.c
- C program that prints a table of enumerated integers, table size given as an argument.

### row_sums.c
- C program with multiple functions, returns the total of the computing operation.
