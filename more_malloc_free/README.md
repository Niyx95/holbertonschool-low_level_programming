## Overview
This directory contains more malloc, free, realloc, calloc exercises provided by Holberton School Australia.

### 0-malloc_checked.c
- function that checks if a pointer is safe and not NULL otherwise it exit the program safely. Caller will not recive a dangling pointer.

### 1-string_nconcat.c
- fucntion that reads a string and copies it into a new buffer and return that pointer.

### 2-calloc.c
- function that wipes out the number of bytes passed and set it to 0.

### 3-array_range.c
- function that creates an array of integers.
