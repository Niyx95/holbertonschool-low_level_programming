## Overview
This directory contains exercies about function pointer provided by Holberton Australia School

### 0-print_name
- function that calls a pointer function and prints name in main.c

### 1-array_iterator.c
- function that iterates trough an array via function pointer in main.c

### 2-int_index.c
- function that return a int if found otherwise -1.

### 3-main.c, 3-calc.h, 3-get_op_func.c, 3-op_functions.c
- simple calculator program made by using pointers, function callbacks, used argc and argv.
