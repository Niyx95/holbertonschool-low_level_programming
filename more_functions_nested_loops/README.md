## Overview
In this directory you will find more exercises about functions and nested loops, provided by Holberton Australia

### 0-isupper.c
- function that returns 1 if uppercase else 0.

### 1-isdigit.c
- function that return 1 if digit else 0.

### 2-mul.c
- function that return a multiplication.

### 3-print_numbers.c
- function that print the numbers from 0 to 9.

### 4-print_most_numbers.c
- function that print numbers from 0 to 9, except 2 and 4.

### 5-more_numbers.c
- function that print a table of integers from 0 to 14.

### 6-print_line.c
- function that print an underscore passed as an argument.

### 7-print_diagonal.c
- function that print a forwardslash and a space passed as an argument.
