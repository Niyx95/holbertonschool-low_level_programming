## Overview
This directory contains the exercises provided by Holberton Australia about stucts in C Programming language.

### dog.h
- header file for initializing a struct. Struct about dog name, age and owner.

### 1-init_dog.c
- function that initializes a dog struct and check if NULL is passed.

### 2-print_dog.c
- fucntion that check if some field of struct is NULL and prints.

### 3-dog.h
- added new type to dog struct.

### 4-new_dog.c
- functions that create a new dog istance, check for failure and free if caller does not recive the instance.

### 5-free_dog.c
- function that frees every istance of a dog if successfull.
