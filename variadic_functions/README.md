## Overview
This directory contains exercise for variadic function provided by Holberton Australia School.

### 0-sum_them_all.c
- function that makes the sum of all passed arguments.

### 1-print_numbers.c
- function that prints numbers and separator passed as arguments.

### 2-print_strings.c
- function that prints strings and separator passed as arguments.

### 3-print_all.c
- function that prints all char, ints, floats passesd as arguments
