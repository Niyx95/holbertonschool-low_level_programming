## Overview
This directory contains all exercies done about C memory, pointers and arrays. exercies provided by Holberton Ausralia.

### 0-reset_to_98.c
- function that reset the pointer to a specific integer.

### 1-swap.c
- function that swaps and updated the values of two pointers.

### 2-strlen.c
- function that return the len of a string.

### 3-puts.c
- function that prints a string.

### 4-print_rev.c
- function that prints a string in reverse.

### 5-rev_string.c
- function that reverse a string.

### 6-puts2.c
- function that takes a string and return every second char.

### 7-puts_half.c
- function that prints the end half of a given string.

### 8-print_array.c
- function that print evry element of an array.

### 9-strcpy.c
- function that copies a string.

### 10-100_atoi.c
- function that converts a string into integers.
