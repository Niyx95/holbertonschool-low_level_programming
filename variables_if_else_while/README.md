## Overview
This directory contains exercises about variables, while loops and if statements

### 0-positiv_or_negative.c
- C program that compares numbers and outputs its type. ( negative, positive or zero if equal)

### 1-last_digit
- C program that outputs the last digit of a number 

### 2-print_alphabet.c
- C program that prints the alphabet in lowercase

### 3-cprint_alphabets.c
- C program that prints the alphabet in lowercase and uppercase

### 4-print_alphabet.c
- C program that print the alphabet, exclude some letters

### 5-print_numbers.c
- C program that print all decimal number from 0 to 9

### 6-print_numberz.c
- C program that prints 0 to 9 with putchar function

### 7-7-print_tebahpla.c
- C program that prints the alphabet in reverse

### 8-print_base16.c
- C program that print all numbers of base 16

### 9-print_comb.c
- C program that prints all digits with a comma and a space
